## 💬 Perguntas e respostas

### Pergunta 1: [Tem-se a seguir, o exemplo de uma lista com o resultado de uma pequena
votação entre três candidatos(as) A, B e C:
L = ['A', 'B', 'A', 'B', 'C', 'C', 'B', 'A', 'A', 'B', 'C', 'B', 'B']
me explique com detalhes como construir uma função capaz de receber como entrada uma lista do tipo acima (com
três candidatos), e fornecer como saída a contagem de cada um deles]
**Resposta (resumo):** [Como funciona a lógica:
Definição da função: Usamos a palavra-chave def para declarar a função e um parâmetro (ex: votos) para receber a lista.
Inicialização das variáveis: Definimos três variáveis zeradas para armazenar os votos dos candidatos 'A', 'B' e 'C'
.
Iteração: Usamos o laço for para percorrer cada item da lista
.
Condicional: Com if, elif e else, verificamos qual é o candidato do voto atual e somamos 1 ao contador correspondente
.
Retorno: Usamos a instrução return para enviar o resultado final de volta.]
